## 讀取 Figma 的注意事項

- 需要使用者的 **Figma 桌面版開著這個檔**，否則回傳 0×0 空 canvas。
- **`get_metadata` 對大 page 會爆**（SSE 在 ~86KB 被截斷）：F2、F3、F6、F7、F11、F13 都會。
  改用 `use_figma` 跑唯讀腳本列 page children 拿 frame ID，再逐個 frame 跑 `get_design_context`。
- Figma 的 top-level page 清單抓不完整（page 是用縮排＋`↳` 命名假造層級），
  要新 page 的 node ID 請直接請使用者在 page 面板右鍵 Copy link。
